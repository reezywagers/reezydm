GITHUB UPLOAD — NO TERMINAL NEEDED

1. Go to https://github.com/new
2. Repository name: kettu-sdm-bulk
3. Choose Public
4. Click "Create repository"
5. On the empty repo page choose "uploading an existing file"
6. Drag in:
   - manifest.json
   - index.js
   - README.md
7. Click "Commit changes"
8. Your Kettu install URL will be:

https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/kettu-sdm-bulk/main/

Paste that folder URL into Kettu → Settings → Plugins → +.
